# 8. 위험도 판단 기준

두 지수 모두 센서값을 0~1로 정규화해 가중합한 0~100점이며, 연기/CO와 기울기 급변은 점수와 별개로 즉시 경보를 낸다. 가중치와 정규화 범위는 초안이고 시연 전 센서 실측으로 조정한다.

## 8.1 정규화

각 센서값 \(x\)는 설정 파일의 최소·최대값으로 0~1 사이 값으로 바꾼다.

$$
n(x) = \min\left(1,\ \max\left(0,\ \frac{x - x_{min}}{x_{max} - x_{min}}\right)\right)
$$

## 8.2 산불 위험 지수

토양 수분·습도·강우가 낮을수록, 기온이 높을수록 위험이 커진다.

$$
F = 100 \times \left[\,0.3\,(1 - n_{soil}) + 0.3\,(1 - n_{hum}) + 0.2\,n_{temp} + 0.2\,(1 - n_{rain})\,\right]
$$

## 8.3 산사태 위험 지수

누적 강우·토양 수분·기울기 변화가 클수록 위험이 커진다.

$$
L = 100 \times \left[\,0.4\,n_{rain} + 0.3\,n_{soil} + 0.3\,n_{tilt}\,\right]
$$

## 8.4 위험 등급과 즉시 경보

| 등급 | 지수 구간 | 지도 색 | 대시보드 동작 |
| --- | --- | --- | --- |
| 정상 | 0~24 | <span class="risk-dot ok"></span>초록 | 표시만 |
| 주의 | 25~49 | <span class="risk-dot caution"></span>노랑 | 표시만 |
| 경계 | 50~74 | <span class="risk-dot warning"></span>주황 | 경보 목록 기록, 화면 알림 |
| 위험 | 75~100 | <span class="risk-dot danger"></span>빨강 | 경보 목록 기록, 강조 알림 |

| 즉시 경보 조건 | 결과 |
| --- | --- |
| 연기 또는 CO 센서값이 임계값 초과 | 산불 지수와 무관하게 '화재 감지' 위험 경보 |
| 기울기 변화가 임계 각도 초과 | 산사태 지수와 무관하게 '사면 붕괴 우려' 위험 경보 |
| 노드 데이터가 정기 주기의 3배 이상 미수신 | '통신 두절' 경보 |

!!! warning "확정 전 항목"
    가중치(0.3·0.2·0.4 등), 정규화 최소·최대값, 연기/CO·기울기 임계값은 센서 실측 후 확정한다. 바꾼 값은 이 페이지와 `NFR-09` 설정 파일에 함께 반영한다.
