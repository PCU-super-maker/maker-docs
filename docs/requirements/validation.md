# 10. 우선순위 및 검증 기준

필수(MVP) 15개 요구사항이 아래 시연 시나리오 4개를 모두 통과하면 메이커톤 목표를 달성한 것으로 본다.

## 10.1 개발 우선순위

| 단계 | 내용 | 관련 요구사항 |
| --- | --- | --- |
| 1단계 | 노드 1기 센서 측정 → LoRa 송신 → 게이트웨이 수신 | FR-N01, N02, G01 |
| 2단계 | 서버 저장·조회 API, 노드 등록 | FR-S01~S03 |
| 3단계 | 위험도 엔진과 즉시 경보 | FR-R01~R04, N03 |
| 4단계 | 지도 대시보드, 노드 상세, 경보 표시, 실시간 갱신 | FR-W01~W04 |
| 5단계 | 시간이 남으면 권장 항목 (그래프, 레이어 전환, 노드 상태, 저전력) | 권장·선택 항목 |

각 이슈 본문의 "개발 단계" 항목에도 같은 단계가 적혀 있다.

## 10.2 시연 시나리오 및 수용 기준

| 시나리오 | 재현 방법 | 기대 결과 (수용 기준) | 관련 요구사항 |
| --- | --- | --- | --- |
| S1. 평상시 감시 | 노드를 그대로 둔 상태 | 지도에 노드가 정상(초록)으로 표시되고 센서값이 주기적으로 갱신 | FR-N01, N02, G01, S01~S03, W01, W02, W04 |
| S2. 산불 위험 상승 | 헤어드라이어로 온도↑·습도↓, 토양 센서를 건조한 흙으로 이동 | 산불 지수가 올라 주의→경계로 바뀌고 화면 알림 발생 | FR-R01, R03, W03 |
| S3. 화재 감지 | 연기(향 등)를 연기 센서에 노출 | 5초 이내 '화재 감지' 위험 경보, 해당 노드 빨강 표시 | FR-N03, R04, W03 |
| S4. 산사태 위험 | 토양에 물을 붓고 노드를 기울임 | 산사태 지수 상승 및 기울기 임계 초과 시 '사면 붕괴 우려' 경보 | FR-R02, R03, N03, W03 |
