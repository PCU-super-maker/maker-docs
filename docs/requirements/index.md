# 요구사항 분석서

!!! info "문서 정보"
    - **프로젝트**: 산림 재난 통합 모니터링 노드 (ForestGuard)
    - **대회**: 배재대 스마트 ICT 메이커톤 · 팀 B-SANG
    - **작성**: 김태호 (기획) · 최초 작성 2026-10-12
    - **상태**: 초안 — 목표치와 위험도 가중치는 팀 합의 후 확정

센서 측정부터 LoRa 전송, 서버 저장, 위험도 산출, 웹 시각화까지 **하나의 동작 가능한 시스템**을 메이커톤 기간 안에 완성하는 것이 목표입니다. 요구사항은 기능 27개, 비기능 9개이며, 이 중 **필수(MVP) 15개**가 시연의 최소 완성 범위입니다.
