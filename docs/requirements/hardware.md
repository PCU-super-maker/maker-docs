# 6. 하드웨어 요구사항

노드 1기는 ESP32 + LoRa 모듈에 센서 5종을 붙인 구성이며, 부품은 팀이 확보 가능한 것을 기준으로 아래 후보 중 확정한다.

| 구성 | 측정 항목 | 판단 용도 | 후보 부품 | 비고 |
| --- | --- | --- | --- | --- |
| MCU + LoRa | - | 측정 제어, 무선 송신 | ESP32 + SX1276/SX1262 일체형 보드 | 국내 LoRa 대역(920MHz대) 지원 모듈 확인 필요 |
| 연기·CO | 연기 농도, CO 농도 | 실제 화재 감지 | MQ-2 (연기), MQ-7 (CO) | 히터 예열 시간·전력 소모 큼 |
| 토양 수분 | 토양 함수율 | 과습(산사태)·건조(산불) 판별 | 정전용량식 토양 수분 센서 | 저항식은 부식 문제로 지양 |
| 기울기 | 3축 가속도·기울기 각 | 사면 붕괴 전 조기경보 | MPU-6050 | 설치 직후 기준 각도 보정 필요 |
| 온습도 | 기온, 상대습도 | 산불 건조도 판단 | DHT22 또는 SHT31 | |
| 강우 | 강우 여부·강우량 | 산사태 주원인 감지 | 빗물 감지 모듈 또는 전도형 우량계 | 감지 모듈은 강우량 측정 불가 |
| 전원 | 배터리 전압 | 노드 상태 표시 | 18650 리튬 배터리 + 전압 분배 회로 | 향후 태양광 충전 확장 |
| 게이트웨이 | - | LoRa 수신, Wi-Fi 전달 | 노드와 같은 ESP32 LoRa 보드 | 노트북 USB 연결도 가능 |

!!! note "부품 확정 후"
    확정한 부품은 이 표의 "후보 부품" 칸을 실제 모델명으로 바꾸고, 비고에 구매처나 핀 배치 문서 링크를 남겨 주세요.
