# 9. 제약사항 및 가정

가장 큰 제약은 실제 산림이 아닌 실내 시연 환경이라는 점이며, 따라서 위험 상황은 센서에 직접 자극을 주어 재현한다.

## 9.1 제약사항

- 개발 기간이 메이커톤 일정으로 한정되어 있어 필수(MVP) 요구사항을 먼저 완성한다.
- 실제 강우·산사태를 재현할 수 없어, 물 붓기·노드 기울이기·연기 발생 등으로 시연한다.
- 국내 LoRa는 920MHz대 비면허 대역을 사용하므로 해당 대역 모듈을 써야 한다.
- MQ 계열 가스 센서는 예열 시간이 필요하고 전력 소모가 커, 시연 시작 전 충분히 예열한다.
- 저가형 센서는 정밀 계측 장비보다 정확도가 낮아, 절대값보다 변화 추이로 판단한다.

## 9.2 가정

- 시연장에 게이트웨이가 사용할 Wi-Fi 또는 노트북 연결이 제공된다.
- 시연 노드는 실물 1~3기이며, 지도의 나머지 노드는 시뮬레이션 데이터로 채운다.
- 노드 설치 위치(위경도)는 관리자가 등록하며, 노드 자체에 GPS는 두지 않는다.
- 기울기 기준값은 노드 설치 직후 측정값으로 한다.
