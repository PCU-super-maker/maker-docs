# 1. 개요

본 시스템은 저가형 IoT 센서 노드를 산림에 분산 배치해 산불과 산사태 위험을 하나의 센서망으로 동시에 감지하고, 지역별 위험도를 웹 지도에 표시한다. 메이커톤 기간 내 목표는 센서 측정부터 LoRa 전송, 서버 저장, 위험도 산출, 웹 시각화까지 하나의 동작 가능한 시스템을 완성하는 것이다.

## 1.1 배경

- 기후 변화로 폭우·가뭄·산불 등 자연재해가 잦아지고 있다.
- 산지가 많은 국내는 건조한 날씨와 강풍으로 산불이 빠르게 확산되며, 해외(네팔)에서는 대규모 산사태 사례가 있었다.
- 기존 고가 계측 장비는 설치 밀도가 낮아 감시 사각지대가 생긴다.

## 1.2 목적

1. 산불·산사태 위험 요소를 단일 센서망으로 통합 감지한다.
2. 사면 붕괴 전 기울기 변화, 산불 발생 전 건조 상태를 사전에 포착해 대피·대응 시간을 확보한다.
3. 저가형 노드로 구축 비용을 낮추고, 노드 추가만으로 감시 범위를 넓힌다.

## 1.3 범위

| 구분 | 메이커톤 범위 (MVP) | 향후 확장 |
| --- | --- | --- |
| 센서 노드 | 프로토타입 노드 (센서 5종) | 다수 노드 현장 분산 배치, 방수·전원 설계 |
| 통신 | LoRa P2P 노드 → 게이트웨이 | 다중 게이트웨이, 장거리 커버리지 |
| 서버 | 데이터 수집·저장, 위험도 산출 | 기상 데이터 연동, 판단 기준 고도화 |
| 웹 | 지도 기반 위험도 대시보드, 경보 표시 | 관계 기관·주민 알림(SMS·푸시) 연동 |

## 1.4 용어 정의

| 용어 | 정의 |
| --- | --- |
| 노드 | 센서와 MCU, LoRa 모듈을 갖춘 현장 측정 단위 |
| 게이트웨이 | 노드의 LoRa 신호를 수신해 인터넷으로 서버에 전달하는 장치 |
| 위험도 엔진 | 센서값으로 산불·산사태 위험 지수와 등급을 계산하는 서버 모듈 |
| 위험 등급 | 위험 지수를 구간으로 나눈 단계 (정상·주의·경계·위험) |
